# Image Metadata Extractor

A Python-based desktop application that extracts and displays metadata from image files.

## Features

- Browse image files
- Preview selected image
- Extract EXIF metadata
- Display image information
- Save metadata report
- Clear results

## Technologies Used

- Python
- Tkinter
- Pillow
- ExifRead

## Installation

```bash
pip install -r requirements.txt
```

## Run the Application

```bash
python metadata_extractor.py
```

## Project Workflow

1. Select an image file
2. Preview the image
3. Click **Extract Metadata**
4. View image information and EXIF metadata
5. Save the report if required
